
# 유란시아서 강론 생성기 (베타)

이 앱은 업로드된 **`urantia_ko.txt`**(유란시아서 한글 본문)를 기반으로
`1:2` 처럼 "편:장" 형식의 입력을 받으면

1. 해당 장의 원문을 추출하고
2. 중학생도 이해할 수 있는 약 1,000자 해설문을 생성하며
3. 5장짜리 PPT 슬라이드용 요약 텍스트를 만들어 줍니다.

## 실행 방법

1. 이 저장소(또는 ZIP)을 내려받아 폴더로 풉니다.
2. 같은 폴더에 **`urantia_ko.txt`** 파일을 둡니다. (파일명은 꼭 같아야 합니다.)
3. 가상환경을 만들고 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

4. 스트림릿으로 앱을 실행합니다.

```bash
streamlit run app.py
```

5. 브라우저에서 열리는 페이지에서 `1:2` 같은 형식으로 장을 입력하고 **강론 생성하기** 버튼을 누릅니다.

## 파일 설명

- `app.py` : 스트림릿 웹앱 본체
- `requirements.txt` : 필요한 패키지 목록
- `urantia_ko.txt` : 유란시아서 한글 본문 (사용자가 제공)

## 제목 파싱 방식

- 사용자가 `1:2`를 입력하면 `1:2.`로 시작하는 줄들을 위에서부터 모읍니다.
- 그 줄들의 **위쪽**으로 거슬러 올라가면서
  - `제 1 편 ...` 처럼 `제 n 편`으로 시작하는 줄
  - `2. 하나님의 현실성` 처럼 `숫자. 제목` 패턴의 줄
  을 찾으면 그것을 제목으로 사용합니다.
- 위 패턴이 없으면 `1편 2장`처럼 기본 제목을 사용합니다.

## 주의 사항

- 이 코드는 공개본/편집본의 줄 구조가 크게 다르지 않다는 전제에서 작성되었습니다.
- 만약 본문이 PDF에서 추출돼 줄바꿈이 다르면, `extract_section_lines()` 부분을 상황에 맞게 조정해 주세요.
